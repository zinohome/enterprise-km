# Spec: 企业级知识管理平台

## 系统概述

企业级知识管理平台是一个基于 Open Notebook 核心引擎构建的企业知识管理解决方案。员工通过桌面应用自动同步本地文档到中央服务器，服务器自动对文档进行分类、构建企业知识库，全员共享使用。

## 功能需求

### FR-1: 桌面应用

#### FR-1.1: 跨平台支持
- 支持 Windows 10+、macOS 12+、Linux (Ubuntu 20.04+)
- 安装包大小 < 50MB
- 支持自动更新

#### FR-1.2: 文件同步
- 用户选择本地目录，自动同步到 MinIO 服务器
- 支持选择性同步（指定子目录/文件类型）
- 同步状态实时显示（同步中/已同步/冲突/错误）
- 增量同步，不重复传输未变更文件
- 冲突检测与提示

#### FR-1.3: 用户界面
- 内嵌 Open Notebook 前端，用户看到的是完整的知识管理界面
- 系统托盘图标，关闭窗口时最小化到托盘
- 支持开机自启
- 个人知识库与企业知识库分开展示

#### FR-1.4: 离线支持
- 无网络时本地正常使用
- 恢复网络后自动同步

### FR-2: 中央服务器

#### FR-2.1: 文件存储
- MinIO S3 兼容存储
- 按用户/团队/共享分类存储
- 支持文件版本管理

#### FR-2.2: 知识处理
- 新文件自动触发 Open Notebook 解析流程
- 自动向量化、生成摘要
- 支持 50+ 文档格式（继承 content-core）

#### FR-2.3: 自动分类
- AI 分析文档内容，自动归类到企业知识树
- 自动提取关键词并打标签
- 相似文档自动聚类
- 知识管理员可审核、调整分类结果

#### FR-2.4: 企业知识库
- 自动构建分类的企业知识库
- 支持知识库权限（私有/团队/公开）
- 知识库搜索（向量 + 全文）
- AI 问答（基于企业知识库）

### FR-3: 多用户与权限

#### FR-3.1: 用户管理
- 用户注册/登录
- 用户角色：admin / manager / editor / viewer
- 用户可加入多个团队

#### FR-3.2: 权限控制
- 知识库级别权限：私有 / 指定团队 / 全员公开
- 操作权限：查看 / 编辑 / 删除 / 发布
- 审批流程：editor 编辑 → manager 审批 → 发布

#### FR-3.3: 数据隔离
- 用户只能看到自己有权限的知识库
- API 层强制权限校验

### FR-4: AI 能力

#### FR-4.1: 智能搜索
- 向量语义搜索 + 全文关键词搜索
- 搜索结果按权限过滤
- 支持按知识库、标签、日期范围筛选

#### FR-4.2: AI 问答
- 基于企业知识库的 RAG 问答
- 回答带出处引用
- 支持多轮对话

#### FR-4.3: 自动处理
- 文档入库自动生成摘要
- 自动提取关键词和标签
- 自动检测知识冲突（新文档与已有知识矛盾）

## 非功能需求

### NFR-1: 性能
- 文档同步延迟 < 5 分钟
- 搜索响应时间 < 2 秒
- AI 问答响应时间 < 30 秒
- 支持 500+ 用户并发

### NFR-2: 安全
- 传输加密（HTTPS/TLS）
- 密码哈希存储（bcrypt）
- API 认证（JWT Token）
- 文件访问权限校验
- 审计日志（谁、何时、做了什么）

### NFR-3: 可靠性
- 服务可用性 > 99.5%
- 数据每日自动备份
- 文件同步断点续传

### NFR-4: 可维护性
- Docker 一键部署
- 服务健康检查
- 日志集中管理
- 监控告警（Prometheus + Grafana）
