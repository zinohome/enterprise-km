# Acceptance Criteria: 企业级知识管理平台

## AC-1: 桌面应用

### AC-1.1: 安装与启动
- [ ] Windows 10/11 上双击 .msi 安装成功，桌面出现快捷方式
- [ ] macOS 12+ 上双击 .dmg 拖入 Applications 成功
- [ ] Ubuntu 20.04+ 上 .AppImage 可直接运行
- [ ] 首次启动显示登录页面，输入正确账号密码后进入主界面
- [ ] 输入错误密码显示"用户名或密码错误"

### AC-1.2: 文件同步
- [ ] 选择本地目录后，目录内文件自动上传到 MinIO
- [ ] 新增文件 5 分钟内同步到服务器
- [ ] 修改文件后自动同步更新版本
- [ ] 删除本地文件后，服务器端标记为已删除（保留历史版本）
- [ ] 托盘图标显示同步状态：同步中（旋转）/ 已同步（绿色）/ 错误（红色）
- [ ] 断网后显示"离线"，恢复网络后自动继续同步
- [ ] 500MB 以上文件弹出提示，用户可选择跳过

### AC-1.3: 系统集成
- [ ] 关闭窗口后应用最小化到系统托盘
- [ ] 右键托盘图标可退出应用
- [ ] 开机自启选项可配置
- [ ] 点击"检查更新"可检测新版本并自动下载

## AC-2: 中央服务器

### AC-2.1: 文件存储
- [ ] 文件上传到 MinIO 后可通过 S3 API 访问
- [ ] 文件按 `users/{user_id}/` 和 `shared/` 分类存储
- [ ] 同一文件多次修改保留历史版本

### AC-2.2: 知识处理
- [ ] 新文件上传后 10 分钟内完成解析和向量化
- [ ] 支持 .docx / .pdf / .md / .txt / .pptx / .xlsx 格式
- [ ] 解析失败的文件标记为"解析失败"，通知用户

### AC-2.3: 自动分类
- [ ] 文档上传后自动建议分类（准确率 > 70%）
- [ ] 自动提取 3-10 个关键词
- [ ] 相似文档自动聚类（同主题文档归入同一分类）
- [ ] 知识管理员可审核、修改、确认分类

### AC-2.4: 企业知识库
- [ ] 知识管理员可创建/编辑/删除知识库分类
- [ ] 知识库支持树形结构（最多 3 层）
- [ ] 搜索响应时间 < 2 秒（1000 份文档规模）
- [ ] AI 问答响应时间 < 30 秒

## AC-3: 多用户与权限

### AC-3.1: 用户管理
- [ ] 管理员可创建/禁用/删除用户
- [ ] 用户可修改自己的密码和头像
- [ ] 用户可加入/退出团队

### AC-3.2: 权限控制
- [ ] 私有知识库仅创建者可见
- [ ] 团队知识库仅团队成员可见
- [ ] 公开知识库全员可见
- [ ] viewer 角色只能查看，不能编辑
- [ ] editor 角色可编辑但不能发布
- [ ] manager 角色可审批发布
- [ ] admin 角色拥有全部权限

### AC-3.3: 审批流程
- [ ] editor 提交发布申请
- [ ] manager 收到审批通知
- [ ] manager 可批准或退回（附理由）
- [ ] 退回后 editor 可修改重新提交

## AC-4: AI 能力

### AC-4.1: 搜索
- [ ] 输入关键词返回相关文档（按相关度排序）
- [ ] 搜索结果仅包含用户有权限查看的文档
- [ ] 支持按知识库、标签、日期范围筛选

### AC-4.2: 问答
- [ ] 提问后返回基于知识库的回答
- [ ] 回答包含引用来源（文档名 + 段落）
- [ ] 知识库中没有相关信息时明确告知"未找到相关信息"
- [ ] 支持追问（多轮对话）

## AC-5: 安全

- [ ] 所有 API 请求需携带有效 JWT Token
- [ ] 密码使用 bcrypt 哈希存储
- [ ] 文件下载需校验用户权限
- [ ] 审计日志记录所有关键操作（登录/创建/编辑/删除/发布）
- [ ] HTTPS 传输加密
