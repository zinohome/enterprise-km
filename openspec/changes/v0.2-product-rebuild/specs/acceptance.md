# Acceptance Criteria: v0.2 产品重建

## AC-1: 制造业知识模型

### AC-1.1: 故障分析报告
- [ ] AI 自动识别 FA 报告，准确率 > 85%
- [ ] 自动提取：现象、根因、措施、零件号、产线
- [ ] 自动关联：同类故障、同一零件、相关 ECN
- [ ] 按零件号/产线/故障类型筛选搜索

### AC-1.2: 工程变更通知
- [ ] AI 自动识别 ECN 文档
- [ ] 自动提取：变更原因、影响范围、生效日期
- [ ] 自动关联：变更前后的零件/文档

### AC-1.3: 工艺规范/质检标准/SOP
- [ ] AI 自动识别文档类型
- [ ] 自动提取对应结构化字段
- [ ] 自动建立文档间关联

## AC-2: 桌面应用

### AC-2.1: 安装包
- [ ] Windows .msi 可正常安装和卸载
- [ ] macOS .dmg 可正常安装和卸载
- [ ] Linux .deb 可正常安装和卸载
- [ ] 安装包 < 200MB
- [ ] 安装过程无需命令行

### AC-2.2: 一键初始化
- [ ] 首次启动自动完成所有环境初始化
- [ ] 初始化时间 < 3 分钟
- [ ] 初始化有进度条
- [ ] 初始化失败有明确错误提示和重试

### AC-2.3: 文件监控
- [ ] 同步目录新增/修改/删除文件，5 秒内检测到
- [ ] 文件监控 CPU 占用 < 5%

### AC-2.4: 系统托盘
- [ ] 关闭窗口最小化到托盘
- [ ] 托盘图标显示同步状态（同步中/已同步/错误/离线）
- [ ] 托盘菜单：打开、暂停同步、通知、退出
- [ ] 退出时停止所有本地服务

### AC-2.5: 离线检测
- [ ] 断网 10 秒内检测到离线
- [ ] 恢复网络 10 秒内检测到恢复
- [ ] 恢复后自动同步

## AC-3: 核心链路

### AC-3.1: 端到端自动化
- [ ] 文件保存 → 同步到 MinIO < 30 秒
- [ ] MinIO 接收 → webhook 触发 < 5 秒
- [ ] 文档处理（解析+字段提取+向量化+分类）< 60 秒
- [ ] 全链路（文件保存 → 审核队列）< 5 分钟

### AC-3.2: 失败重试
- [ ] 任一环节失败自动重试 3 次
- [ ] 3 次失败后标记为"处理失败"并通知
- [ ] 失败任务可手动重试

### AC-3.3: 制造业字段提取
- [ ] 5 种文档类型识别准确率 > 85%
- [ ] 字段提取准确率 > 80%
- [ ] 人工可修正提取结果

## AC-4: 搜索服务

### AC-4.1: 混合搜索
- [ ] 关键词搜索 < 500ms
- [ ] 语义搜索 < 1s
- [ ] 按权限过滤，无权限文档不出现
- [ ] 按知识类型/零件号/产线/日期筛选

### AC-4.2: AI 问答
- [ ] 基于搜索结果的 RAG 问答
- [ ] 回答带出处引用
- [ ] 响应 < 30 秒
- [ ] 无法回答时明确告知

### AC-4.3: 知识图谱
- [ ] 文档间关联关系正确
- [ ] 可视化展示
- [ ] 支持图查询

## AC-5: 冷启动

### AC-5.1: 快速开始向导
- [ ] 首次登录后显示 5 步向导
- [ ] 每步有明确的操作和反馈
- [ ] 5 分钟内完成向导

### AC-5.2: 示例数据
- [ ] 50+ 份示例文档
- [ ] 覆盖 5 种知识类型
- [ ] 导入后自动处理、可搜索、可 AI 问答

### AC-5.3: 批量导入
- [ ] 支持导入 100+ 文件目录
- [ ] 导入进度实时显示
- [ ] 导入报告：成功/失败/跳过

## AC-6: 权限与安全

### AC-6.1: 权限控制
- [ ] 私有文档仅作者可搜索
- [ ] 团队文档仅成员可搜索
- [ ] 公开文档全员可搜索
- [ ] 权限变更 30 秒内生效

### AC-6.2: 审计日志
- [ ] 所有操作有记录
- [ ] 可按用户/时间/操作类型查询
- [ ] 日志不可篡改

### AC-6.3: 数据安全
- [ ] HTTPS/TLS 1.3 传输加密
- [ ] 密码 bcrypt 哈希
- [ ] 每日自动备份
- [ ] 支持数据导出

## AC-7: 知识分析

### AC-7.1: 知识仪表盘
- [ ] 文档总量、分类分布、热门文档
- [ ] 知识缺口分析
- [ ] 使用统计

### AC-7.2: 智能推荐

- [ ] v0.1 所有 173 个测试仍然通过
