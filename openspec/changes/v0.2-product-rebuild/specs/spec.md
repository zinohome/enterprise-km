# Spec: v0.2 产品重建

## 系统概述

v0.2 将 v0.1 从"通用企业知识管理原型"重建为"面向制造业的 AI 原生知识管理平台"。核心变化：
- **垂直定位**：聚焦制造业，深度理解 FA/ECN/工艺规范/质检标准/SOP
- **放弃改造 Open Notebook**：嵌入原版作为个人知识库，企业知识库完全自建
- **端到端自动化**：文件保存到可搜索，全链路零人工操作
- **真正的桌面应用**：文件监控、原生通知、离线检测、一键初始化
- **冷启动方案**：50+ 示例文档、5 步向导、5 分钟看到价值

## 功能需求

### FR-1: 制造业知识模型

#### FR-1.1: 故障分析报告 (FA Report)
- 结构化字段：现象、根因、措施、零件号、产线、设备、日期、作者
- AI 自动从文档中提取上述字段
- 关联：同类故障、同一零件、同一产线、相关 ECN
- 搜索：按零件号、产线、故障类型筛选

#### FR-1.2: 工程变更通知 (ECN)
- 结构化字段：变更原因、影响范围、审批记录、生效日期、变更前后对比
- 关联：变更前后的零件/文档/FA 报告
- 搜索：按零件号、变更类型、日期范围筛选

#### FR-1.3: 工艺规范 (Process Spec)
- 结构化字段：工艺参数、适用产品、版本历史、编制日期
- 关联：相关质检标准、相关 SOP
- 搜索：按产品、工艺类型筛选

#### FR-1.4: 质检标准 (Quality Standard)
- 结构化字段：检测方法、合格标准、抽样方案、适用产品
- 关联：相关工艺规范
- 搜索：按产品、检测类型筛选

#### FR-1.5: 标准操作流程 (SOP)
- 结构化字段：步骤、注意事项、所需工具、版本历史
- 关联：相关故障案例、相关工艺规范
- 搜索：按岗位、设备筛选

### FR-2: 桌面应用（重写）

#### FR-2.1: 真正的桌面应用
- Rust 原生文件系统监控（notify-rs），5 秒内检测变更
- 原生系统通知（同步完成、新知识入库、审批请求）
- 系统托盘：实时同步状态、最近通知、快捷操作
- 离线检测：网络断开 10 秒内检测，恢复后自动同步
- 开机自启

#### FR-2.2: 一键初始化
- 首次启动自动完成所有环境初始化
- rclone + SurrealDB：从安装包预置二进制直接复制（秒级）
- Open Notebook：在线 pip install，有进度条
- 全程无需用户干预

#### FR-2.3: 跨平台安装包
- Windows .msi、macOS .dmg、Linux .deb/.rpm/.AppImage
- 安装包 < 200MB
- 安装过程无需命令行

#### FR-2.4: 联邦搜索
- 一个搜索框，同时查询本地个人知识库 + 企业知识库
- 结果区分"个人"和"企业"标签
- 企业结果支持 AI 问答

### FR-3: 核心链路自动化

#### FR-3.1: 文档处理链路
```
文件变更 → rclone 同步 → MinIO webhook → Worker 下载
→ 解析 → 制造业字段提取 → 向量化 → 分类 → 知识图谱关联
→ 审核队列 → 管理员通过 → 发布到搜索服务
```
- 每个环节自动触发下一个
- 失败自动重试 3 次
- 处理状态可追踪

#### FR-3.2: 异步任务队列
- Redis + RQ 管理文档处理任务
- 支持优先级
- 任务失败告警

#### FR-3.3: 制造业字段提取
- 上传文档后，AI 自动识别文档类型（FA/ECN/工艺规范/质检标准/SOP）
- 自动提取对应结构化字段
- 人工可修正

### FR-4: 企业知识库搜索服务

#### FR-4.1: 混合搜索
- Meilisearch 全文搜索 + Qdrant 向量搜索
- RRF 合并排序
- 按权限过滤
- 按知识类型/零件号/产线/日期筛选
- 响应 < 500ms

#### FR-4.2: AI 问答（RAG）
- 基于搜索结果的 RAG 问答
- 回答带出处引用
- 支持多轮对话
- 响应 < 30 秒

#### FR-4.3: 知识图谱
- 文档之间的关联关系（FA→零件→ECN→SOP）
- 可视化展示
- 支持图查询："这个零件涉及的所有变更"

### FR-5: 冷启动

#### FR-5.1: 快速开始向导
- 首次登录后 5 步引导
- 步骤 1：选择行业（制造业）
- 步骤 2：导入示例数据
- 步骤 3：配置同步目录
- 步骤 4：邀请团队成员
- 步骤 5：完成，进入主界面

#### FR-5.2: 示例数据
- 50+ 份基于博世真实场景的示例文档
- 覆盖 5 种知识类型
- 导入后自动解析、向量化、分类、发布
- 可搜索、可 AI 问答

#### FR-5.3: 批量导入
- 从本地目录/SharePoint/文件服务器导入
- 支持 Markdown/Word/PDF/TXT
- 导入进度显示
- 导入报告

### FR-6: 权限与安全

#### FR-6.1: 权限控制
- 文档级权限：私有 / 团队 / 公开
- 搜索强制过滤
- 权限变更 30 秒内生效

#### FR-6.2: 审计日志
- 所有操作记录：谁、何时、做了什么、结果
- 支持按用户/时间/操作类型查询
- 不可篡改

#### FR-6.3: 数据安全
- 传输加密：HTTPS/TLS 1.3
- 认证：JWT + bcrypt
- 数据备份：每日自动备份
- 数据导出：支持批量导出

### FR-7: 知识分析

#### FR-7.1: 知识仪表盘
- 文档总量、分类分布、热门文档
- 知识缺口分析：哪些领域文档少
- 使用统计：搜索量、问答量、活跃用户

#### FR-7.2: 智能推荐
- "处理过这个故障的人还看了..."
- "你可能感兴趣的文档"
- 新人学习路径推荐

## 非功能需求

### NFR-1: 性能
- 文件变更到同步开始 < 5 秒
- 文档处理（解析+向量化+分类）< 60 秒/份
- 搜索响应 < 500ms
- AI 问答 < 30 秒
- 支持 500+ 用户并发

### NFR-2: 可靠性
- 核心链路每环节失败自动重试 3 次
- 任务队列持久化
- 服务健康检查 + 自动重启
- 可用性 > 99.5%

### NFR-3: 可安装性
- 安装包 < 200MB
- 首次启动到可用 < 3 分钟
- 无需手动配置任何组件
- Docker Compose 一键部署服务端

### NFR-4: 安全性
- 传输加密（HTTPS/TLS 1.3）
- 密码哈希（bcrypt）
- JWT Token 认证
- 审计日志不可篡改
- 数据备份每日自动执行
