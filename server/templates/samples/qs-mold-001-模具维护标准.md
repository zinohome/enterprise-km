# 注塑模具维护标准

## 基本信息
- **标准编号**: QS-MOLD-001
- **检测类型**: 模具维护
- **适用模具**: 所有注塑模具
- **版本**: v1.0

## 维护周期

| 维护项目 | 周期 | 执行人 |
|----------|------|--------|
| 模具表面清洁 | 每班次 | 操作员 |
| 冷却水道检查 | 每周 | 模具工 |
| 型腔尺寸检测 | 每月 | 质检员 |
| 顶出机构润滑 | 每 5000 模次 | 模具工 |
| 全面拆检 | 每 50000 模次 | 模具工程师 |

## 型腔尺寸公差标准

| 模具寿命阶段 | 允许偏差 |
|-------------|----------|
| 新模具 (0-10000 模次) | ±0.01mm |
| 正常使用 (10000-50000 模次) | ±0.02mm |
| 后期 (50000-100000 模次) | ±0.03mm |
| 超期 (>100000 模次) | 需评估是否返修 |

## 维护记录
每次维护后需在模具台账中记录：
- 维护日期、维护项目、执行人
- 型腔尺寸实测值
- 异常情况及处理措施
