# 注塑机操作标准流程

## 基本信息
- **SOP 编号**: SOP-INJ-001
- **适用岗位**: 注塑操作员
- **适用设备**: 注塑机 IM-300/IM-500
- **版本**: v2.1

## 操作步骤

### 1. 开机前检查
1.1 检查设备电源、气源是否正常
1.2 检查冷却水是否畅通
1.3 检查料斗内原料是否充足
1.4 检查模具是否安装牢固

### 2. 开机
2.1 打开主电源开关
2.2 启动液压系统
2.3 设定料筒温度，等待升温至设定值（约 30 分钟）
2.4 确认各段温度达到工艺规范要求

### 3. 生产
3.1 选择对应产品的工艺参数配方
3.2 手动试模 5 模，检查产品外观
3.3 确认产品合格后切换为自动生产
3.4 每 2 小时检查一次产品外观和尺寸
3.5 每 4 小时记录一次工艺参数

### 4. 停机
4.1 停止自动生产
4.2 清空料筒内余料
4.3 关闭加热系统
4.4 待温度降至 100°C 以下后关闭液压系统
4.5 关闭主电源

## 注意事项
- 模具温度必须达到设定值后才能开始生产
- 严禁在设备运行时伸手进入模具区域
- 发现异常声音或气味立即停机检查
- 更换模具时必须执行 LOTO（上锁挂牌）

## 所需工具
- 温度计
- 卡尺
- 手套（耐热）
- 安全眼镜
