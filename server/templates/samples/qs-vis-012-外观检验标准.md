# 注塑件外观检验标准

## 基本信息
- **标准编号**: QS-VIS-012
- **检测类型**: 外观检验
- **适用产品**: 所有注塑件
- **版本**: v2.0

## 检测方法
在标准光源（D65，1000 lux）下，距离产品 30cm 目视检查。

## 合格标准

| 缺陷类型 | 允许标准 |
|----------|----------|
| 缩痕 | A 级面不允许；B 级面深度 < 0.1mm |
| 飞边 | 不允许 |
| 气泡 | 直径 < 0.5mm，数量 < 3 个 |
| 色差 | ΔE < 1.5 |
| 划伤 | A 级面不允许；B 级面长度 < 5mm |
| 熔接痕 | A 级面不允许；B 级面不明显 |

## 抽样方案
- 正常检验: GB/T 2828.1，AQL=0.65，Level II
- 加严检验: AQL=0.25（连续 2 批不合格时触发）
