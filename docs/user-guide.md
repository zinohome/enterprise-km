# 企业知识管理平台 — 员工使用手册

## 快速开始

### 1. 安装桌面应用

从 IT 部门获取安装包，双击安装。

- Windows: `企业知识管理-Setup.exe`
- macOS: `企业知识管理.dmg`
- Linux: `企业知识管理.AppImage`

### 2. 登录

打开应用，输入 IT 部门分配的账号密码。

### 3. 配置同步目录

1. 点击左侧「同步状态」
2. 点击「选择同步目录」
3. 选择本地存放工作文档的文件夹
4. 应用会自动将文件同步到企业知识库

### 4. 使用知识库

- **浏览知识**：点击「企业知识库」，按分类浏览文档
- **搜索知识**：在搜索框输入关键词，可筛选分类
- **上传文档**：将文件放入同步目录，自动上传并分类

### 5. 提交审批

重要文档需要审批后才能发布到企业知识库：
1. 在文档页面点击「提交审批」
2. 管理员审核通过后自动发布

## 常见问题

**Q: 同步失败怎么办？**
A: 检查网络连接，确认右下角托盘图标为绿色。红色表示连接失败，联系 IT。

**Q: 如何查看我的文档？**
A: 点击「我的知识库」查看个人文档。

**Q: 文档分类不对？**
A: 系统自动分类，如有误可联系管理员调整。
